# ConfluenceVersOutlineV2

Ce script a pour but de migrer une base de documents présent sur Confluence pour arriver tel quel dans Outline. Le processus : Export des documents confluence sur la machine locale en markdown -> exécution du script python -> qui importera automatiquement nos documents locaux (anciennement ceux de confluence) vers Outline en modifiant si nécessaires les documents afin qu'Outline les supportent tout en respectant l'arborescence de base présent dans Confluence ainsi que la structure interne des documents
